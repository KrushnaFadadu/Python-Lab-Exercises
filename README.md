# Python Lab Exercises

## About the Project

This repository contains 16 Python programming lab exercises prescribed in the TLEP syllabus.

The objective of these exercises is to understand Python programming concepts through practical implementation and problem-solving.

Each program is uploaded separately in an individual Python file.


## List of Lab Exercises

### Module I – Python Basics
1. Basic Python Programs (Variables, Operators, Input and Output)
2. Simple Calculator
3. Area Calculation

### Module II – Control Statements and Functions
4. Number Guessing Game
5. Prime Number Program
6. Factorial Program
7. Fibonacci Series Using Recursion

### Module III – Lists and Dictionaries
8. Contact Book Using Lists and Dictionaries
9. Student Grading System
10. Frequency Counter Using Dictionaries

### Module IV – File Handling and CSV
11. Log File Reader Program
12. Student Data Manager Using Files
13. CSV-Based Payroll Management System

### Module V – OOP and Random Module
14. Bank Account System Using OOP
15. Library Management System
16. Dice Simulator Using Random Module

## How to Use This Repository

1. Open the required Python program from this repository.
2. View and understand the source code.
3. Download the program if you want to execute it.
4. Run it using a Python 3 interpreter.
